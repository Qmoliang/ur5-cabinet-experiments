# KV-NEO-01: known-volume external controller comparison

Frozen before closed-loop results. Source: Haviland and Corke, NEO, RA-L 2021, DOI 10.1109/LRA.2021.3056060. Paper https://arxiv.org/abs/2010.08686 ; author example https://jhavl.github.io/neo/ .

## Question and cases
Can the NEO core QP reach the same cabinet target as the successful LiuQP known-volume case? One deterministic original start; no statistical or generalization claim. Cases: LiuQP ellipsoid rerun, NEO matched influence (surface distance di=0.046m = safety 0.006 + original search near 0.04), NEO paper influence (di=0.3m). Both NEO cases use ds=0.006m, xi=1, lambda_q=.01, lambda_slack=1/max(L1 position error,1e-6), translational Yoshikawa manipulability gradient coefficient=1. Joint damper eta=1, influence .9rad as author example, stopping padding .015rad to match this task. These are fixed before results; no selection of successful tuning.

## Method fidelity and adaptations
Reimplement NEO paper Eq4/5,15/17,19-29 using MuJoCo kinematics and locally pinned quadprog 0.1.13, same-QP SLSQP only if necessary. Preflight identified OSQP precision sensitivity near zero task error; dense active-set quadprog chosen before any closed-loop run. This is a position-task adaptation of the published core, not the authors' full benchmark reproduction or their official package execution. Three translational slack variables replace six pose slack variables because original task has no orientation requirement. Analytical elimination delta=v-Jqdot preserves the QP exactly, including +/-10 slack bounds. Translational manipulability sqrt(det(Jt Jt^T)) uses central finite-difference gradient (step1e-5rad), checked for convergence. Each obstacle damper uses closest separation normal; all pairs inside influence included, no Liu pruning or NEAR cost. Share only robot/geometry code, not Liu solve/state logic. The optional retreat heuristic in paper SecVI is absent, matching the public core example. Distances ds, joint padding, task gain/cap and workspace adapt to the shared task; using original 5cm safety would change geometric feasibility.
