## 为什么 U 大了会挡住末端？

第二章 2.7 中，沿单位方向 n 的椭球支撑是 sqrt(n^T U n)。几何核心和误差相加时，支撑为 sqrt(n^T Q n)+sqrt(n^T U n)。U 是位置误差集合的形状矩阵，不是直接按样本数量缩小的统计协方差。

在同一个方向上，U 的支撑多出 2 mm，就可能使安全间隙少 2 mm。控制器随后把间隙除以 dt，限制球心朝障碍的速度；球心速度等于该球自己的 J_i qdot。前臂受限也会影响末端前进，因为二者共享关节速度。

## 两个新候选的数学区别

I30：固定坐标系 R，逐轴记录 h_k=max(|r_k^T(p-c)|+sqrt(r_k^T U_raw r_k))。盒子被 U=R diag(3h_k^2) R^T 包含。覆盖正确，但 sqrt(3) 外扩可能比旧方法更大。本轮负结果保留，不推荐仅凭“只外包一次”就使用它。

J30：先令 d=p-c。用原有 Young 不等式 B=(1+beta)U_raw+(1+1/beta)dd^T 包住平移后的测量椭球。第一帧选定 R，以后固定；对每个原始 B 计算 R^T B R，每行对角加非对角绝对值和，逐轴累计最大值 D。由于 D-R^T B R 对称对角占优且对角非负，它是半正定矩阵，故 R D R^T 包含 B。不会再把帧外包当作新测量重新合并。

J30 避免一部分重复外扩，但固定 R 未必适合后来另一相机的观测方向。因此可能下沿变薄、顶板反而变厚，必须用全方向包含检查和实际闭环来判断。

## 读结果时需要区分

1. 真实盒子控制能到达：说明这个任务存在由该诊断控制器找到的运动轨迹；不证明相机算法成功。
2. 覆盖检查通过：说明观测误差集合被代理覆盖；不等于所有真实障碍都被相机提前看见。
3. MVT oracle 通过：说明索引没有漏掉应有候选；不等于多级比单级快。
4. 终点小于 1 mm：还需要保持 50 周期及其余安全/时限审计。
5. 本轮连续盒审计证明机器人证书与柜体的整段分离；不涵盖机器人自碰撞或未知空间。
