# 环境已知的球/椭球完整体积包络实验

这是一个独立的新实验，不使用深度相机、点云、CenterVox或在线地图，也不修改 `LiuQP_v43_v44` 中冻结的原 v4.3/v4.4。

## 本实验真正覆盖什么

冻结抽屉场景的8个真实盒体被确定性切分成368个三维子盒，最大边长75 mm。球和椭球使用完全相同的子盒中心、尺寸和编号：

- 球半径是子盒的半对角线：\(r=\|h\|_2\)。
- 椭球半轴是：\(a=\sqrt3h\)。

每个子盒的8个顶点都经过解析包含检查。球和椭球是凸集，所以8个顶点在代理内即可推出整个子盒体积都在代理内。这不是表面点云拟合，也不存在0.1 mm的“压扁核心椭圆”。本实验椭球三个半轴的总体范围约为25.98–62.07 mm；球半径范围约为48.08–53.70 mm。

## 已完成的真实结果

| 表示 | 代理数 | 完整体积覆盖 | 最终误差 | 1 mm保持50周期 | 穿透周期 |
|---|---:|---:|---:|---:|---:|
| 球体积外包 | 368 | 通过 | 314.164573 mm | 否 | 0 |
| 椭球体积外包 | 368 | 通过 | 0.000620 mm | 是 | 0 |

椭球首次完成连续成功的时刻为15.72 s。两组都运行3000个20 ms控制周期，没有RRT、中间目标、随机扰动、相机输入或真值碰撞回退。

球版主运行在接近几何边界后大量达到OSQP迭代上限，因此不能仅凭主运行把受阻全部归因于几何。为排除这个混杂因素，`results/sphere_same_qp_slsqp_validation/` 在OSQP停止时用SLSQP求解完全相同的QP，没有改变约束、目标或控制路径；1634次回退全部成功求解，但最终误差仍为314.164571 mm。最终状态的线性规划审计还表明，硬约束允许的最大瞬时目标进展仅为 \(7.26\times10^{-8}\) m/s。

因此，本场景目前支持的准确结论是：在相同75 mm实体分块和相同LiuQP下，球的各向同性体积外包形成了局部几何闭塞；具有真实板厚的椭球体积外包保留了通道并到达目标。该结论只针对这个场景和尺度，不能外推为所有球覆盖必然失败。

## 观看

双击：

- `查看球体积版.cmd`
- `查看椭球体积版.cmd`
- `查看体积对照.cmd`

MuJoCo窗口按键：`1`球版，`2`椭球版，`V`显示/隐藏体积代理，`R`机械臂证书球，`空格`暂停，`N`单步，`0`开头，`F`末态。

物理柜体始终存在；透明红色球或橙色椭球是完整体积外包代理，蓝色球是机械臂证书，绿色小球是目标。

## 重新运行

双击 `运行球体积版.cmd` 或 `运行椭球体积版.cmd`。命令行等价入口：

```powershell
& D:\anaconda3\envs\simple\python.exe -B D:\MuJoCo\LiuQP_known_volume\run.py sphere
& D:\anaconda3\envs\simple\python.exe -B D:\MuJoCo\LiuQP_known_volume\run.py ellipsoid
```

主日志位于 `results/sphere/` 和 `results/ellipsoid/`。真实汇总表是 `tables/results.csv`；详细解释门见 `results/comparison.json`。
