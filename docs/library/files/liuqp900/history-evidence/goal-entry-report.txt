本轮真正推导并实现的内容：
1. 静态终态 IK 与局部回退段认证，提供进入轴和受阻部位的目标侧几何；这不证明当前到该入口的连通性。
2. 当前任务雅可比 K_sigma 与零空间 N_sigma=I-K_sigma^dagger K_sigma。正常时跟踪末端进入场；绕行时跟踪受阻点的安全法向/切向分量。完整终态只作为零空间姿态偏置。
3. 切向方向跨代理变化持续运输，法向修正不再退出绕行阶段；避免重复切回最终点吸引而反复制动。
4. 以实际净特征进展和目标侧相容性决定退出，并保留逐段、逐制动可认证的防回陷半空间；其目标终态始终在内，但不能保证连通性。
5. 原硬约束、追加约束及新目标的 KKT 作用映射成原执行 QP 的有效梯度，并验证实际执行解；QP 与制动安全证书的数值保留量已对齐。

失败分析中区分了：旧增广余量求解器假停滞、局部姿态投影混淆构型分支、自碰证书与提案差异、OPEN/BYPASS 抖动、实际方向族耗尽、原 QP 暂态不可行、在线激活历史污染和时序敏感性。各类证据单独保存，未把它们统称为局部极小。
两次精确回放表明，原 QP 暂态不可行可在一次已有认证制动后恢复；这支持有限恢复分支，不支持放宽硬安全或在空可行集里凭目标函数产生动作。

结论边界：
这是已实现的研究控制器，不是全局逃逸定理。目标端信息是局部的，没有获得 RRT 反向树的连接关系。固定快照、在线触发及延迟压力的结果必须一起判断。
目标姿态是内部准备参考；到达仍按原末端位置任务判定，不声称额外完成了未给定的末端姿态精确跟踪。
没有真实硬件、持续新感知、传感噪声或跨 seed/场景验证；控制与安全认证耗时单独记录，不宣称硬实时。
