Release decision: NOT accepted as a stable replacement: final failures and/or success-regression losses remain

Observed causes in the original four failures:
1. No full terminal-entry certificate was called, and no no-return memory was committed. Those four failures were NOT caused by memory rejecting an otherwise valid entry.
2. The pulled-back witness matrix was almost always rank six. Projecting posture preparation into the nullspace of ALL rows numerically deleted that task. Representative projector norms were about 1e-14.
3. The worst goal-side support-plane witness changed 905--1684 times. 60--68 locally accepted windows did not surpass earlier best margins. Clearing one virtual witness did not imply sustained entry progress.
4. A fixed terminal IK posture and contraction were insufficient. A static terminal candidate is locally safe, not certified reachable from the current trapped posture. Trying other original terminal candidates helped earlier in the motion but alone failed all four old end-state replays.

Implemented structural changes:
Keep maximin continuation improvement as feasible inequalities; retain the two-feature posture objective instead of nulling the entire witness matrix. Use a consistent scalar RMS physical-penetration merit to rank and persist terminal options. Only original static terminal IK candidates are compared; no intermediate configuration is optimized.
When both actual continuation and actual end-effector-plus-two-feature progress stall, switch to two-component physical surface motion of the currently blocking body: normal correction and a persistent goal-conditioned tangent. Project the original two posture features into this TWO-row task nullspace. Temporarily worsening the virtual entry merit is permitted, while all physical safety rows and braking certificates remain unchanged.
Commit original-form no-return halfspaces only after actual goal-side feature progress and a continuous braking-memory certificate. The memory feature origin stays fixed when the terminal target changes. Actual motion and feature revisits inform direction reversal; no waypoint graph is constructed.
Reset progress evidence at the actual original-controller/escape handoff and at terminal-target changes. This fixes the measured T2 regression whose guarded controller had inherited 956 cycles of pre-escape non-progress evidence.

Measured remaining mechanisms:
In the first failed final seed4 original-start repeat, the retained surface point 54 had already opened to 123.76mm, while the recomputed solved original QP was blocked primarily by point 47. In the seed4 saved-state failure, the retained point 51 had 61.02mm clearance while the active constraints had shifted to point 23, self pair (42,55), and point 49. The controller had transported the obstacle proxy for the OLD robot point, but did not transfer its controlled robot frame. This is a concrete stale-blocker failure, not evidence that the physical scene is unreachable.
Two final failed states (one saved-state replay and one success regression) were independently confirmed to have infeasible original velocity constraints by HiGHS feasibility LPs, as well as the original QP solver, despite passing the independent physical safety audit. The physical guard and the controller operating-distance buffer are different invariants. Physical safety and goal-containing no-return planes do not guarantee recursive QP feasibility. Solver infeasibility certificates are NOT interpreted as optimal dual forces in the diagnostic.

Limits:
Natural compute-delay repeats are a robustness check at the same seed, not independent unseen samples. All four T0 cases participated in development. The 35 regression records include duplicate earlier replays, not 35 distinct scenes.
Local terminal merit, a goal-side halfspace, or a positive tangent velocity do not prove future connectivity. Near-equivalent terminal IK solutions can have different indices; finite index history is not a complete recurrence model. A locally useful surface direction can cease to be useful as the blocking link changes. See read-only final_failure_diagnosis for measured remaining cases; hypotheses there are not causal proofs.
All execution remained MuJoCo kinematic feedback with the original safety margins and numeric tolerances. No RRT, route search, six-dimensional path planning, physical robot, or new online perception was used. Historical frozen observation maps may reflect earlier planner-driven sensing; historical routes are never read by this controller.
Original frozen source and old results remain unchanged. The last candidate is isolated in this study and is not automatically promoted. No global completeness or general unknown-environment escape guarantee follows from these tests.
