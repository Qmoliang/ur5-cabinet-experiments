二、总耗时
共同目标池重新计算并计时，三方法使用相同目标和相同准备成本；不是复用旧批次的目标准备时间。
总计费时间 = 共同目标准备 + 实际进程启动/导入/模型与后端初始化 + 直接连接预查 + 搜索/区域生成 + 独立验收 + GCS + 连续安全检查 + 共同离线时间参数化。
共同阶段物理上只算一次，向每方法计入相同实测成本；因此这是公平共享阶段计费，不冒称每条记录都在各自进程里重新计算共同目标。

  椭球8项：中位2.988秒；
  球2项：中位3.590秒。
IRIS-Fast和Precise：
  各10项均在14秒总预算截止，没有成功总耗时可统计。
  14秒是失败删失点，不是成功耗时中位数。
  没有共同成功样本，不能计算可靠的RRT/IRIS成功耗时加速比。

三、本轮真正对齐了哪些工程能力
1. 相同任务空间特征：
   [末端位置/.15, q3, q4]；相同posture_feasible_count>0模式选择。
2. 相同IK步进：
   复用原position_ik；任务空间步长.12、max_nfev=12、IK误差<=1e-5；
   关节空间步长.08；与原RRT64次局部步进逐项对比，64次均一致，误差容许1e-10。
3. 目标偏置和采样尺度：
   任务空间每5次偏置一次，特征范围为起点/全部目标并集加减.7；
   关节空间每10次偏置一次，padding .5/1.5/3.5。
4. 多目标与双端：
   所有共同目标都进入调度，不再只锚定最近目标或截取前16个。
   两端、目标、尺度轮转；预检验证了27目标×两端×三尺度均有调度机会。
   实际预算下仍未必能为每个目标创建区域，不能将接口支持所有目标解释为每目标已经获得等量计算。
5. 面向区域的前沿推进：
   使用官方GCS交集检查产生的真实连通分量；
   从已有分量中的区域种子沿相同IK/关节步进探索，在离开该区域前退回半步，形成仍位于旧区域内的新种子，以支持重叠覆盖。
   没有调用RRT求出完整路线再供IRIS使用。
6. 预算：
   移除12次区域尝试上限及旧的2048候选耗尽即终止规则。
   双方候选路径未通过连续安全检查后都继续尝试，直到成功或总时间截止。
   内部IRIS每个区域的20次内层资源上限保持不变；未通过统计的区域不能放行，且不会终止外层求路。

任务空间/IK用于候选引导。IRIS区域仍是六维关节空间集合，未把五维特征空间的概率当成六维体积概率。
这一对齐不意味着树搜索和区域覆盖具有相同数据结构、计算成本或全部工程成熟度。

四、独立验收没有回退
使用上次修复并通过保存区域验证的独立均匀拒绝验收，核心源文件逐项校验未变。
Fast epsilon/delta=.1/.1，Precise=.01/.05，tau=.5；风险逐内层分配，样本量向上取整，验收流与造面流分离。
环境6.5mm、自碰撞5mm、目标6.6mm、目标误差1mm等标准保持。
C-space margin=.01、relax_margin=false等也没有为通过而放宽。
本轮实际保存的226个区域，均逐一匹配到了完整的独立验收记录、A/b摘要、样本数、碰撞数与通过决定；不是仅检查“存在返回值”。
原生验收事件和最终保存区域的数量可因预算边界后的上层拒收不同，本文使用实际保存区域口径。
没有额外重做全部区域的大规模体积分数审查；“正确走过独立验收”也不是每个区域绝对无碰撞或每条路径安全的声明。

六、还暴露了什么工程缺口
87次中间区域构造退出均为固定C-space退让要求与当前中心太靠边界的冲突：
  Fast70次：68次来自端点锚定，1次任务空间前沿，1次关节前沿；
  Precise17次：16次端点锚定，1次任务空间前沿。
这说明主要压力集中在目标/端点附近。RRT只需到达一个满足物理安全标准的点；当前IRIS接入还试图在该点附近长出满足额外退让规则的区域，两者不是同一种要求。
本轮保留了重复端点尝试、失败日志和时间，没有在观察失败后缩小margin或换目标重跑。
安全候选被拒后，当前流程继续生成覆盖，却没有把具体碰撞见证反馈为区域细化/候选排除约束；某些不安全最短路仍可能再次出现。
GCS仍按当前区域集合重建求解，不是已经充分优化的增量图缓存实现。
因此，虽然本次请求的任务/IK/多目标/预算接口已经实际对齐，不能宣称所有工程问题都已解决，更不能把0/10归为IRIS-ZO理论的失败。

七、能支持哪些结论
可以支持：
  本次实现并验证了相同局部引导参数、全部目标调度及无次数截断的总预算；
  在这套14秒冷启动集成与小样本上，未观察到相对当前RRT的成功率或总耗时收益；
  主要剩余困难是目标附近覆盖、安全候选选择，以及可靠统计验收的真实成本。

  IRIS-ZO算法普遍不如RRT；

  在线298/300或275/300结果发生变化。
