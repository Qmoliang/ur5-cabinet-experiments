轮2：连续占据支持体

用户于 2026-09-10 明确纠正目标：最终末端误差 严格小于 0.18 mm，不是 0.018 mm。原正式配置仍为3000周期，原到达判据仍为小于1mm连续50周期；额外同时核对用户的0.18mm最终误差要求。

为何修改覆盖对象

首版保存于 revisions/round1，原完整运行记录不覆盖。首版把测量不确定性触及的5mm网格整个单元作为障碍，再用椭球外包，在狭窄通道引入了额外膨胀。本轮明确不再宣称完整 raster occupied cell 覆盖，而改为连续观测支持体覆盖。这是模型修订，不是放宽原始测量覆盖容差。

NativeIncrementalOccupancyMap 仍运行并保存 free/occupied/unknown 图。代理来自与之并行维护的观测体素证据：IncrementalMatchedProxyManager 的每个 CenterVox 保存代表点 c、融合形状 U，以及历史测量证书来源。原源码先认证所有原始测量支持体经重定位后都包含于相应 E(c,U)。原地图的 categorical occupied 栅格仅保存状态，没有截格前连续边界；因此不能靠该状态恢复准确支持体，必须保留观测证据。

覆盖传递

令第 k 个原测量支持体为 S_k = x_k + E(0,U_k)，所属体素为 i。

原增量管理器的 frame/历史合并审计给出：S_k ⊆ c_i + E(0,U_i)。本轮直接发布中心 c_i、核心 Q_i=U_i，额外不确定性0、offset0。逐项验证新中心与来源中心完全相等、新 Q 与来源 U 完全相等。

因此所有 S_k 仍被覆盖。没有有限方向抽样替代包含证明，没有过滤低计数/遮挡历史测量，也没有按目标位置或真值删除代理。不同体素的包络可重叠，但不再额外增加整块网格的角点外扩。

这里的 Q 表示连续占据证据的完整测量包络，并非纯障碍物内部几何。不能把 U 重命名为核心后声称“物体厚度已重建”；本轮改变的是分组尺度和覆盖对象，控制实际使用全部局部完整包络。

控制路径

所有连续局部体积代理都实际进入 MVT/AABB 与控制器查询。额外 U 全零时，原 online_helpers 返回 None，原 controller 自动走球—椭球精确距离求解（2.6，也是额外 U=0 时2.7的特例）。并未把 uncertainty 当软约束。控制器、原生DLL、任务反馈、6mm余量、初态与目标保持不变。

本轮检查

  • 原管理器的全历史测量覆盖审计；新逐体素中心/形状完全等同于来源支持体。
  • U正定有限、半轴不超过70mm、ID唯一且空间稳定、快照不被后帧改写。
  • 完整运行中记录实际窄相求解分支、到达与<0.18mm门槛、碰撞及扫掠审计、周期耗时。
  • volume_cell_coverage_applicable=false：明确不适用完整5mm方格覆盖检查，不用true冒充首版的覆盖对象。

TSDF尚未实现；未知实体内部未填充。若后续目标要求“真实完整物体厚度”，需另有多视角闭合证据或明确的建模先验，不能由本轮结果推定。

增强审计对象修正

增强审计最终直接检查管理器保存的全部历史逐帧测量支持体，不要求上一版聚合外包整体被新外包包含。外包允许在保持原始支持体覆盖时收紧。逐帧原始U另有直接包含检查。矩阵检查最大特征值阈值固定1+1e-9。完整数据与失败试跑见达标报告。
