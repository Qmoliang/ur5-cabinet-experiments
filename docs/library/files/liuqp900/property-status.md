## 已给出数学证明（均以所列假设为前提）
- **P1** KKT梯度重写的同状态等价性。
- **P2** 姿态零空间中的线性可达方向及正确秩维数。
- **P4** Cartesian记忆对已记录位置的排除与精确目标纤维保留。
- **P5** 给定保守二阶界时的端点一致抛物线下界。
- **P6** 非退化切向投影不会无依据反向。

## 有条件、且不能直接升级成整个冻结程序保证
- **P3** 证书消费的递归可接受性：需要初始证书、有效Oracle、状态一致与原子提交；当前程序有已知提交顺序异常。
- **P7** 终态射线仅有满足当前约束且未被改变的一步收缩性质，保持/制动不自动继承。
- **P8** 最弱余量LP只给当前固定见证的线性预测性质，实际非线性净进展没有普遍保证。
- **P9** 本批静止求解、恒速保持的理想各关节速度界为0.2rad/s；数值误差及非零初速另计。

## 仅由当前实验支持的效果
三组到达率、严格成功率、增益/退化与耗时；各机制触发频率；已测轨迹的独立安全/原QP/记忆审计。
