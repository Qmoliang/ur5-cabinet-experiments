# 正式实验协议 v5.2：等价 Loewner 复用与完整重跑

> 冻结时间：2026-09-01。继承 v5.0 与 v5.1 的全部几何、控制、相机、地图、
> 候选族、尺度和验收门。本文只冻结一个经过逐数组等价验证的实现级延迟修复。

## 1. v5.1 负结果

v5.1 的十次正式运行永久保留。5/5 椭球均严格到达小于 1 mm，5/5 球均在
342--345 mm 误差处受阻；但完整验收失败。椭球 r01/r03/r04/r05 的同一个
`drawer_left` 真值表面样本分别迟到 2、5、2、3 个周期，均为 `late=1,
never=0`；椭球 r05 有 2 次 deadline miss，球 r02 有 1 次 deadline miss。
这些运行全部进入 v5.1 分母，不得改名为 validation 或删除。

只读剖析证明相机在源周期 117--120 已看到该表面，但相同帧的椭球证书在
周期 243--246 才进入控制快照。迟到帧的代理桶拟合耗时 2.01--2.06 s；根因
是代理发布延迟，不是永久盲区，也不是目标、椭球轴长或可观测性审计阈值。

## 2. 唯一允许的实现变化

`fit_matched_voxel_proxies.refine` 对一个不可变递归节点原先先为不确定性膨胀
判定计算

\[
U_J=\operatorname{LoewnerJoin}\{U_i\mid i\in J\},
\]

随后又为证书最长支持上限对完全相同的 `J` 和 `U_i` 重算一次 `U_J`。v5.2
只在同一次 `refine(J)` 调用内复用第一次结果。不得跨节点近似、缓存旧帧结果、
减少 eigensolver 精度、改变递归分支或跳过覆盖审计。

冻结 CenterVox 的补丁前后重放显示：`centers`、球半径、核心椭球、外包椭球、
不确定性、标量残差、CenterVox、owner 索引等十个数组逐元素完全相同，代理
NPZ 的 SHA-256 同为
`5fcffbd11c8bf6f712ef880e63fa0a536ccaa897274ffc878a11ea9480038983`。
Loewner 调用数由 8283 降至 5047；同一带 profiler 的重放更新时间由
4405.407 ms 降至 3803.957 ms。该数据只证明工程等价与热点消除，不代替正式
闭环实时门。

## 3. validation 与正式矩阵

400 周期椭球 validation 必须先通过覆盖、不可约性、observed-before-risk、
snapshot age、控制 p99、deadline 和零穿透门。它不计入正式结果，也不能用
于挑选控制参数。

validation 通过后，按下列交替顺序从头运行全部组，不能只补跑曾失败的椭球：

| 表示 | 运行 ID |
|---|---|
| sphere | `v52_r01`、`v52_r02`、`v52_r03`、`v52_r04`、`v52_r05` |
| ellipsoid | `v52_r01`、`v52_r02`、`v52_r03`、`v52_r04`、`v52_r05` |

顺序固定为 sphere r01、ellipsoid r01、sphere r02、ellipsoid r02，依此类推。
所有参数仍为 v5.1 冻结值。五次椭球必须全部严格到达且逐次通过非任务门；
球任务失败可作为结论，但也必须逐次通过非任务门。任一失败均原样进入分母，
不得继续补跑到凑够五次通过。

## 4. 交付门

v5.2 只有在 126 项完整回归、十次 source hash 一致、正式五次聚合、连续截面、
同点云 30/50/70 mm 不可约覆盖、MVT/AABB/SIMD oracle 等价、三状态审计、
MuJoCo viewer 与 SHA-256 清单全部通过后，才可标记 D7/D8 完成。
