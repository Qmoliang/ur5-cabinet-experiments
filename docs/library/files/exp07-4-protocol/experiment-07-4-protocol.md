# 实验 07.4：在原始测量阶段保留不同方向的误差集合

状态：开发协议，结果产生前登记。沿用 07.3 场景及目标，不修改历史日志。

## 固定条件与数据
UR5e、相机位姿及 160x90 两台深度相机；50 Hz/45 s、目标误差 <1 mm 保持 50 周期，安全距离 6 mm、光轴误差 3 mm、CenterVox 7.5 mm、核心种子半轴下限 3 mm、代理半径上限 70 mm。起点使用第7版原有五个偏移。最终目标、控制权重、速度、QP容差均与07.3一致；没有姿态引导或真值控制反馈。

开发数据：07.3 ET30五条轨迹实际发布的源相机姿态；逐帧还原并核对深度数量及工作空间裁剪，不将这些数据作为独立泛化样本。主闭环五个固定起点全部保留，不筛选失败。

## 方法与消融
ET30：现行 separate_uncertainty。P30：已有 partitioned_separate_uncertainty，仅在整帧外包后分方向。D30：本轮新 raw_directional_uncertainty，在原始 U 的主轴方向上确定分组，同一空间体素保留多个独立误差叶；不同相机仍更新同一个地图，无相机ID专用代理。

D30 无向主轴用绝对值最大坐标作为规范面，将其余两坐标与主坐标之比 [-1,1] 分为4段，总48方向格；主轴各向异性不足2时分到第49个格。分组仅影响保守程度，不以角度阈值近似误差几何。每格固定首个观测批次的误差矩阵坐标系，直接累计原始平移误差矩阵的对角占优上界，继承07.3 J30的全矩阵包含检查。每空间体素最多49个叶；不会用平均、交集或1/sqrt(N)删除误差。

## 阶段门与执行
1. 独立集合包含、跨帧历史、两个不同方向同时进入一帧的测试；旧模式回归。
2. 同输入：五个ET30源轨迹重放，至少检查每帧原始误差到叶的包含、最终原始方向支撑/原方法/分叶方法、叶数及内存开销。先执行种子0开发全链更新测量。记录全部负结果。
3. 只在覆盖通过后短程ET30/P30/D30；若D30更新成本显著导致地图滞后，在本轮如实记录，不放松安全/观测门槛。
4. 新模式D30与同期ET30五起点45s闭环；P30为机制参照，先做种子0完整运行，若已能解释机制不追加五起点性能声称。所有运行使用相同固定参数。
5. 汇总覆盖、MVT oracle、真实穿透、代理扫掠、观测及时性、控制时限、成功率/误差/代理数；证据门未全过不得称完整安全成功。连续柜体盒审计不等于自碰撞或未知空间证书。

## 统计与效率边界
逐种子公开原始日志及终点误差，报告中位数/最大值，小样本不作显著性声称。在线轨迹会分化，同输入几何消融与真实闭环分开。开发计时仅供发现性能问题；不在后台重负载下声称MVT或实时性收益。未研究鸟笼泛化。
