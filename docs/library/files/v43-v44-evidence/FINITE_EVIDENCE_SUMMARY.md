# v4.3 椭球 / v4.4 球：有限补证统计

> 本报告仅汇总冻结制品和独立只读审计。每种表示只有一次确定性闭环运行，
> 因此不进行 t 检验或人为构造 p 值。微基准重复样本不是独立任务试验。

## 核心结果

- v4.3 椭球：最终误差 0.176860 mm，严格成功；控制器 p99 18.992 ms。
- v4.4 球：最终误差 263.724 mm，失败；第 168 周期后连续 2832 周期零速度。
- v4.4 覆盖：3697 球覆盖 14504 CenterVox；无独占见证球 0，完全包含球 0。

## 必须保留的证据边界

- 两组场景 XML 相同：True；初始 q 完全相同：True。
- 最终 CenterVox 哈希相同：False。两条轨迹改变了后续观测，因此这不是严格同点云配对。
- v4.4 当前固定 x,y 竖线闭合：True；同一 x 的整个物理截面闭合：False。
- 最终球快照的正面截面闭合：False；最终椭球中心开球半径 9.184 mm。
- 完整可观测性门：球 False，椭球 False。

因此，现有冻结结果支持‘该球型 LiuQP 运行发生持久局部硬约束死锁，椭球运行成功’，
但尚不支持‘球证书封闭所有可扰动构型’或‘同一 CenterVox 下只有表示变量不同’。

## 当前原生宽阶段离线回放

- 椭球负载：全量/MVT 标量/MVT AVX2 中位数分别为 2.3776/0.1758/0.1061 ms。
- 球负载：全量/MVT 标量/MVT AVX2 中位数分别为 3.5793/0.0737/0.0578 ms。
- 两组所有候选 ID 均与 float32 O(N) oracle 一致。当前 C++/DLL 哈希不匹配历史冻结二进制，故这是当前内核的离线补证，不是历史运行计时复现。
