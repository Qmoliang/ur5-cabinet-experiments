执行器新增59个严格成功中，44个原已物理安全到达但QP/制动审计未过；14个原未到达；1个原到达但物理安全失败。新控制的109个新增均为原A未到达。不能把前者都归为新控制收益。

新控制新增109例中，continuation机制激活109例，表面绕行20例，构型重复重选1例。触发频率不等于独立因果贡献。静止求解与恒速保持还产生约0.2 rad/s的条件性有效速度界，执行器不是透明外壳。

退化与安全失败

  • C→A严格退化：iris_bins_t3 / seed 8，C在8.16秒仿真时间内成功，A运行300秒失败，B成功。
  • A→B严格退化：iris_bins_t0 / seed 17，A成功，B停在1.38 mm；C可物理安全到达，但有10个原QP行违规周期。因此C→B严格口径双方失败，物理安全到达口径仍是退化。
  • C另有iris_bins_t0 / seed 6到达但环境间隙5.9575 mm低于6 mm，按安全失败保留。
  • A的共享执行器一致性异常及数值求解失败仍保留，不把这些全称为数学局部极小。

共同严格成功时，C→A的中位数为3.776→7.832秒（127对）；A→B为9.131→185.053秒（185对）。B的初始化开销明显，不能宣称每例加速。

C补跑整批112.09分钟，含审计113.09分钟。超时停止与收尾消耗如实记录，任何完整单次超过1200秒的结果不算成功。

条件与限制

C/A/B均为MuJoCo运动学反馈和历史冻结观测地图。每次最多300秒仿真、1200秒完整计算；C在后续批次执行，延迟和负载影响没有通过同时随机化完全消除。没有“新控制＋原执行器”第四组，不能分离所有交互。
