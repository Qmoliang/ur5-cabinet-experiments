# 查看真实物体、球与椭球证书

关闭旧回放窗口，再从本目录启动。默认显示不透明柜子和机械臂真实外观。
快捷键在回放窗口与中文控制面板都有效，面板按钮与快捷键执行相同操作。

## 三种显示方式

| 键 | 显示方式 |
|---|---|
| F1 | 只看真实柜子和机械臂，关闭证书 |
| F2 | 隐藏柜子和机械臂实体，只看环境代理和机器人证书球 |
| F3 | 真实物体与证书叠加，柜子保持不透明 |
| B | 独立显示／隐藏真实柜子 |
| H | 独立显示／隐藏机械臂真实外观 |
| O | 独立显示／隐藏环境球或椭球核心 |
| R | 独立显示／隐藏机器人证书球 |
| V | 显示／隐藏全部证书，保留实体显示状态 |
| T | 可选的柜板透明开关，默认关闭 |
| C | 机器人原始碰撞几何（与证书球不同） |
| U | 单独显示椭球不确定性分量 |

## 切换实验与回放

- **1 球、2 椭球**：切换当前控制器的配对实验。不会把 LiuQP 切成 NEO，也不会更改 NEO 的约束预算。当前组无配对结果时，面板提示不可用。
- **左右方向键**：当前组上一／下一实验；也可用中文下拉框。
- **空格**：暂停／继续；**0**：从头播放；**N**：单步；**F**：最终姿态；**S**：首次到达确认。
- **M**：下一次在线地图发布，跳转后暂停。
- 鼠标左拖旋转、右拖平移、滚轮缩放；Shift 加拖动切换水平旋转／平移。

| 启动文件 | 主要配对 | 地图行为 |
|---|---|---|
| 01_已知环境LiuQP.cmd | K01 球 / K02 椭球 | 固定已知地图 |
| 02_历史管线4.3和4.4.cmd | H02 球 / H01 椭球 | 按原记录发布更新 |
| 04_在线LiuQP与NEO.cmd | O01 球 / O02 椭球；O03/O04；O05/O06 | 按原记录发布更新 |

橙红色为环境球，蓝色为椭球核心 Q，绿色为机器人证书球。在线地图显示序号、代理数、观测源时间和发布时间，不是每个显示帧都重建。单独显示的 Q 与 U 不是完整的 Minkowski 和包络。

这仍是原实验记录回放，不是重新运行控制器。没有代理快照的中止实验会提示不可用。显示模式只影响屏幕，实验轨迹、相机记录、控制器与封存结果均未修改。
