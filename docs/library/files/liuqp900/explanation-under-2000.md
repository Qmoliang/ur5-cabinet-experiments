# 新版是如何工作的：2000字以内讲解

我们研究的是：机械臂没有一条预先规划好的路线，只知道目标和当前可用的障碍地图，能否在保持原安全标准的同时，绕开阻挡并到达目标。

原来的LiuQP每一步都解一个速度优化问题：尽量靠近目标，同时满足碰撞、关节、速度、加速度等限制。但在我们的实现中出现两类问题。一是眼前安全的动作，可能把机器人带到下一步原QP无解或无法按原约束停车的状态；二是机器人虽然一直安全，却在障碍附近停住、反复绕回，或始终挪不动真正受阻的部位。新版把这两件事分开处理。

**第一层是共同执行器，负责动作能否执行。** 它不只检查下一步，还检查每个短运动前缀之后，是否仍有一条满足原约束的制动轨迹，能够停在可继续保持的状态。命令必须和实际姿态、上一速度及当前约束版本一致。新命令不合格，就沿已经认证的备份停车；不能假设零速度永远可行。计算等待仍占用总时间，但不被误当成绕行已经运动了很久。这个执行器有代价：停走和低速保持会改变行为，所以它本身的收益必须单独测量。

**第二层是新控制，负责怎样继续取得进展。** 它先在目标附近找有限个安全终态，再检查“从当前姿态直接收缩到某个终态”这条固定线是否安全。若还不安全，就找出线上最严重的阻塞，调整当前速度，使进入条件逐渐改善。这里没有搜索整条路线，也没有优化一串未来姿态，但确实使用了静态逆运动学和未来线段验证。

如果准备仍停滞，就改为控制真正受阻的机器人部位，例如肘部或前臂，让它沿表面持续绕行，而不是只盯着末端。阻塞部位变了，旧方向会投影到新表面的切平面，避免突然反向。系统还检查完整关节构型是否绕回旧位置；走了很远却回到原处，不算进展。

退出绕行也有要求：实际更接近目标，而且恢复原任务的动作与停车备份都能通过认证，才提交一条防回陷记忆并恢复目标控制；或者整条终态收缩线已经认证通过，进入终态。记忆保留精确目标位置，但不保证所有通路都保留，因此仍可能失败。

我们用相同300个输入比较三组，共900次：C是原目标和原执行方式，A只换共同执行器，B再加终态初始化与新控制。物理安全到达分别为174、186、294次；再要求全程原QP及末态备份等审计时，严格成功分别为128、186、294次。C到A严格新增59、退化1；A到B新增109、退化1。因此执行器和控制都有收益，不能把全部改善归给新控制。

B仍有6个失败，完整墙钟中位数约145秒，包含约79秒的初始化中位数；两项中位数不能相加拆分单次运行。A的完整墙钟中位数约41秒，新方法并非普遍更快。已有证明限于条件下的QP解等价、证书续接、切向投影和记忆性质等；“所有可达目标都能逃出停滞并在预算内到达”尚未证明，也没有实机或全新环境保证。

旧RRT系统的300次加进来，确实是所选1200条运行记录。但它依靠规划路径、使用不同协议，不能与新三组当成公平四臂排名。当前最准确的结论是：新版在这批输入上显著改善了安全到达，并把执行保障、进展机制、失败和计算成本分开给出了证据。
